## 📖 About Project

This repository contains simple and beginner-friendly C programs to understand important DSA concepts.

✨ In this project, you will learn:

- 🔍 Finding Missing Elements in an Array
- 🔄 Rotating an Array
- 📊 Sorting an Array
- 💻 Writing Efficient C Programs

## 📂 Project Structure

| File Name | Description |
|------------|-------------|
| 📄 `Missing.c` | Program to find missing elements in an array |
| 📄 `rotate.c` | Program for array rotation |
| 📄 `short.c` | Program for sorting an array |
| 📄 `README.md` | Project documentation |

## ▶️ How to Run

### Compile

```bash
gcc filename.c -o output
```

### Execute

```bash
./output
```

Example:

```bash
gcc Missing.c -o missing
./missing
```
